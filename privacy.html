Privacy policy

Matthias Assistant is a private tool used by a single person, its owner. It has no other users.

What data is accessed

With the owner's consent, the tool reads the owner's own health and fitness data from the Google Health API with read-only permissions (activity and fitness, health metrics and measurements, nutrition, sleep). In addition, only when the owner explicitly asks for it, the tool writes the owner's own nutrition logs and workout entries to the owner's account (nutrition and activity write permissions), and it can correct or delete entries it created. It never changes or deletes any other data.

How it is used and stored

The data is downloaded to and stored only on the owner's own computer, where it is used to create personal summaries for the owner. It is not published, sold, shared with or transferred to any third party, and it is not used for advertising.

Revoking access

Access can be revoked at any time in the Google Account under Security → Third-party apps and services.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
